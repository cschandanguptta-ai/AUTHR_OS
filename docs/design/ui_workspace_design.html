Workstation switcher
layout/WorkstationSwitcher.tsx
Five studios separated by ✦. Right cluster: bundle title, lease LED (green = live lease, amber = READ-ONLY foreign lease), bundle path, maintenance kebab. Lock dot re-probes project_lock_status on click.

Project Binder
layout/ProjectBinder.tsx
Manuscript tree (books → chapters with status dots), cast with role badges, lore categories, story threads. Opens the NewChapter / Character / Lore / Thread modals; chapter search filters segments.

Dynamic Inspector
layout/DynamicInspector.tsx
Contextual rail fed live by the stores: segment prosody chrome (type, speaker, voice, IPA, emotion presets) + chapter meta + AI context. Width persists in workspaceStore.paneWidths.
4
Manuscript canvas
editor/LexicalCanvas.tsx + nodes/*
Lexical AST editor: SegmentParagraph, SpeakerGutter, EmotionChip, FoleyTrigger nodes. Three view modes — clean · script · read-along — plus typewriter (distraction-free) mode. Autosave per mutation.

Fluid split panes
layout/Cockpit.tsx · SplitHandle
Custom pointer-event splitters (no library): drag to resize, double-click resets to defaults. Binder/inspector can fully collapse; the canvas never re-mounts, so undo history survives.
